# 🌱 Krishi Setu – Smart Agriculture Platform

**Krishi Setu** is a web-based smart agriculture platform designed to help farmers access useful agricultural information and resources in one place.

The platform aims to make farming information more accessible through digital tools and user-friendly web pages.

## 🚀 Project Overview

Krishi Setu acts as a digital bridge between farmers, agricultural information and useful farming resources. It provides different sections to support farmers in making informed agricultural decisions.

## ✨ Features

- 🌾 **Crop Recommendation** – A dedicated section for crop recommendations.
- 🚜 **Farming Tools** – Access to farming-related tools.
- 🧪 **Fertilizer Information** – Information about fertilizers.
- 💧 **Irrigation Adviser** – Irrigation-related guidance.
- 🌦️ **Weather Information** – Weather-related information.
- 🔐 **Login Page** – User login interface.
- 🏛️ **Government Schemes** – Information about agricultural schemes.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive functionality

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the `krishisetu` folder.
4. Open `index.html` in your web browser.
5. Explore the available website pages.
